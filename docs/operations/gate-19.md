# Human Gate 19 — Optional behavior training

Status: **DEFERRED**. Combined implementation release: **0.20.0**.
Dataset/recipe/comparison support is implemented; no actual adapter is validated.

Before any training, identify a measurable behavior deficit, review at least 20
synthetic examples without personal facts, record the base revision and dataset
hash, and use a separately approved supported training environment. No personal
conversation collection or upload is automatic.

Compare base and adapter using identical full real-model regressions and human
conversations. Check privacy, tools, uncertainty, multilingual behavior and identity.
Require meaningful target improvement, no critical regression, and a tested return
to the base model. Record **DEFERRED** or **REJECTED** if benefit is absent. Loss alone
does not pass this gate. Do not call the current training recipe GPU-verified.
