# Human Validation Gate 15

Status: **NOT_STARTED**. Version: **0.15.0**.

The user's next-task and completion requests authorize implementation. Gate 14
and earlier unperformed human gates remain pending. Automated checks are not a
human validation pass. Follow [the Vision guide](vision.md).

1. Sign in and confirm Vision starts off. Enable with the owner passphrase.
   Read a harmless technical error screenshot and compare OCR with its pixels.
2. Try a small-font, rotated, blurry and ambiguous image. Check the preview and
   uncertainty. OCR must not imply general scene understanding.
3. Open harmless Notepad text, arm, select it, and verify a visible notice
   appears before the one-window capture without taking focus. Repeated
   capture must require another opt-in. Cancel during the countdown.
4. Try a private title, minimized window and unsupported application. Check
   denial and that no broader screen image is substituted.
5. Disable, leave Vision, hide ADAM, sign out and restart. Check observations
   disappear, new logins start off and traces contain no image or OCR payload.
6. Confirm no camera input or ordinary-chat visual input is claimed. Verify
   image text asking for clicks, commands or permissions causes no action.
7. If you separately configure a compatible local visual model, check scene
   results against the image, test ambiguity and verify a text-only server is
   rejected before it receives an image. Record the actual model and hardware.

Record PASS / PASS WITH NOTES / REOPEN / BLOCKED, observations and limitations.
