# Security reports

Do not post credentials, conversation databases, portable backups, private paths,
phone pairing keys or full private traces in public issues.

Report a vulnerability privately to **maliksaad277@email.com**, including the affected
release, a minimal fictional reproduction and the permission boundary involved.
This contact is for reporting; the project does not automatically send diagnostics.

ADAM's boundaries assume a trusted Windows account. They do not protect against
someone who already controls that account, the Python interpreter, app binaries
or the operating system. See [the threat model](docs/public/THREAT_MODEL.md).
